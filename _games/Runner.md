# Dino Runner

## Instructions

1. Refer to the dino-run folder.
2. In the folder are two sub folders: scenes and assets.

3. The `scenes` folder contains images of each action the sprite character can respond or is affected in the game. These include:
   - Game Start
   - Rock Coming Up
   - Jump Rock
   - Flyer Coming Up
   - Flyer Jump
   - Flyer Duck
   - Game Over

4. The assets folder contain the assets in each of these scenes and it also includes a single asset with multiple actions to create animated movement for the dinosaur dying (dead), the dino ducking, the bottom grass field the dino runs on, the dino in an idle state (not moving), the dino jumping, the rock which the dino must jump over, the dino running, and the bird dino which is just like the rock, something to jump over or duck under.

## Game Play

1. The game shows and stores the highest score,
2. The player clicks the play button
3. The Dino sprite starts running in place as the ground moves.
4. The movement of the ground starts off slow.
5. Randomly a Rock or Bird appears from the right of the screen and flows with the ground to the left.
6. Before the sprite comes in contact with either the enemy object it might either jump or duck.
7. Every time the Sprite dodges the enemy it gets a point.
8. Every 10 seconds the ground and the enemies speed up from the right to the left side like belt by 10% of the current speed.
9. If the Sprite comes in contact with the enemy the sprite dies. It is game over. And if the player beat the last highest score they can put in their name and it will show their score on the start page.
